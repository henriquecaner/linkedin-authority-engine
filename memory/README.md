# Substrato de Memória Local

Esta pasta armazena o aprendizado cumulativo e o histórico de performance do autor.

Os arquivos são criados automaticamente durante o onboarding (`/init` ou pedido de onboarding no chat) e atualizados após cada postagem:

- `winning-hooks.md`: Padrões de ganchos que performaram acima da média.
- `topic-performance.md`: Histórico de temas, pilares e pontuações no 360Brew.
- `voice-profile.md`: Ajustes e calibrações de tom de voz.
- `learnings.md`: Regras livres e aprendizados contextuais de cada sessão.
