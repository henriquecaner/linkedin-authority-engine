# 16 Tipos de Conteúdo

## Visão Geral

Escolha o tipo baseado no objetivo e no que você tem para compartilhar.

---

## 1. Truth and Hope (Verdade e Esperança)

**Quando usar:** Compartilhar verdade difícil + oferecer caminho

**Estrutura:**

→ Verdade dura/difícil

→ Por que importa

→ Mas existe esperança

→ Aqui está o caminho

---

## 2. Old Way, New Way

**Quando usar:** Introduzir nova abordagem sobre tópico existente

**Estrutura:**

→ Como era antes

→ Problemas do jeito antigo

→ O jeito novo

→ Por que funciona

---

## 3. I Learned Something This Week

**Quando usar:** Compartilhar insight recente de experiência pessoal

**Estrutura:**

→ O que aprendi

→ Contexto

→ Por que foi importante

→ Como aplicar

---

## 4. Statistics Post

**Quando usar:** Começar com estatística surpreendente

**Estrutura:**

→ Estatística chocante

→ Por que isso acontece

→ O que significa

→ Como se beneficiar

---

## 5. The Magic of X

**Quando usar:** Destacar benefícios de tópico específico

**Estrutura:**

→ O que é "X"

→ Por que é mágico

→ Benefícios específicos

→ Como começar

---

## 6. Before-and-After

**Quando usar:** Compartilhar história de transformação

**Estrutura:**

→ Situação antes

→ O que mudou

→ Situação depois

→ Lição aprendida

---

## 7. Round-up List

**Quando usar:** Coletar recursos sobre tópico específico

**Estrutura:**

→ Introdução do tema

→ Lista de recursos

→ Por que cada um é valioso

→ Convite para contribuir

---

## 8. Behind the Scenes

**Quando usar:** Mostrar bastidores de processo

**Estrutura:**

→ O que está criando

→ Processo/desafios

→ Aprendizados

→ Próximos passos

---

## 9. Tell a Story

**Quando usar:** Conectar emocionalmente

**Estrutura:**

→ Personagem

→ Situação/conflito

→ Ação tomada

→ Resultado

→ Lição

---

## 10. How-to (Tutorial)

**Quando usar:** Ensinar processo

**Estrutura:**

→ Título claro "Como fazer X"

→ Passo a passo numerado

→ Dicas específicas

→ Resultado esperado

---

## 11. Contrarian Opinion

**Quando usar:** Chamar atenção com visão única

**Estrutura:**

→ Opinião contrária clara

→ Por que acredita nisso

→ Dados/experiência que suportam

→ Abertura para debate

---

## 12. Lessons from Mentor

**Quando usar:** Falar sobre lições de mentor

**Estrutura:**

→ Quem é o mentor

→ Contexto do aprendizado

→ Lições específicas

→ Como aplicou

---

## 13. Mistakes and Failures

**Quando usar:** Compartilhar vulnerabilidade

**Estrutura:**

→ O erro/falha

→ Como aconteceu

→ Consequências

→ O que aprendeu

---

## 14. Create a Villain

**Quando usar:** Criar contraste para passar mensagem

**Estrutura:**

→ Apresente o "vilão" (pensamento ou ideia)

→ Por que é um problema

→ Como prejudica

→ A alternativa/solução

---

## 15. Framework/System

**Quando usar:** Apresentar método estruturado

**Estrutura:**

→ Nome do framework

→ Contexto/problema que resolve

→ Passos numerados

→ Resultado esperado

---

## 16. Data-Driven

**Quando usar:** Apresentar insights baseados em dados

**Estrutura:**

→ Dado principal

→ Contexto da análise

→ Insights derivados

→ Aplicação prática

---

## Guia de Escolha

| Objetivo | Tipos Recomendados |
| --- | --- |
| Educar | How-to, Framework, Statistics |
| Inspirar | Story, Before-After, Mentor |
| Engajar | Contrarian, Villain, I Learned |
| Converter | Before-After, Magic of X |
| Autoridade | Data-Driven, Framework |
